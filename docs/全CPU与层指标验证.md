# 全 CPU 分窗观察与独立层指标

验证日期：2026-09-29。

## 页面与数据

- 五个标签：概览、线程、CPU / NUMA、网络、时延 / 深度。
- 线程、CPU / NUMA、时延 / 深度共用所选区间、预热显示开关及本次/上次轮次。切换标签保持同一 3 秒区间。
- CPU / NUMA 默认显示本地主机全部逻辑 CPU，包含空闲核；支持主机及 NUMA 筛选、单核详情和明细表。
- 每核展示同窗 busy、User、System、IRQ、SoftIRQ、Idle，关联 NUMA、socket/core 与 SMT 同核 CPU。IPC 仍属于单线程 PMU 计数，当前不提供整核 IPC。
- 该轮 `cpu_inventory` 声明 CPU 范围；该轮该窗 `cpus` 提供实际负载。缺失为“—”，不使用另一轮记录或整轮均值补齐；没有清单的旧数据标“范围未知”。
- 时延 / 深度仅展示同窗 `layers`，保留层、范围、时延 μs、深度。层采集方法未接入时显示“待接入”，不以 fio 整轮时延替代业务层指标。
