# 三秒观测验证

验证日期：2026-09-29。

## 功能与数据口径

- schema_version=1 兼容旧批次，新增 observation 与 sample_windows；预热和正式测试独立记录。
- 默认 30s 预热、60s 正式测试、3s 采样，包含 10 个预热区间与 20 个正式区间。
- 单线程保留 PID/TID/starttime、CPU 端点、CPU%、同窗 PMU 计数与 SMT 拓扑；SMT 负载限定同主机、同区间。
- guest 分窗完成数缺失时 IOPS=null；有效 IPC 使用 running/enabled 覆盖并独立验证计数起止，不从全轮计数复制每点。
- 对比允许有限端点抖动，仅同采样计划、同阶段的双向唯一匹配有效。实际区间与时长保持原样。
- layers 预留各层时延和深度，目前未接入产品层采集方法。
