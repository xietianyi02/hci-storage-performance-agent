# 版本页加载验证

2026-09-29，本机 `http://127.0.0.1:8000/#version`，现有 11 批次、44 个 fio 场景。

## 原因

旧首屏先读取全部批次完整记录 19,012,352 B，再并行请求本轮 4 个场景的完整配对 16,498,628 B，共 35,510,980 B。包含 480 个采样窗及 70,080 行分窗 CPU 数据。后台每个配对还重新解析所有批次；大字典响应经过重复递归编码。页面打开只是读取本地保存的记录，没有触发集群测试。

## 改动

- 首屏读取轻量目录、所选批次场景摘要和所选场景概览；线程、CPU / NUMA、时延 / 深度标签按需读取完整采样。
- 不可变批次派生目录与场景索引，启动时补齐旧记录。配对保留完整 fio、来源、环境、真实时间及同时间排序语义。
- 分窗采样与分析评价分别缓存，采样最多保留三对；切换标签复用，换场景取消旧请求。读取失败可重试，尚未读取与实际缺失分开显示。
- 技术页首次打开不再预先请求案例、运营概览、知识库及工具资料；进入这些页面后加载。
- 版本接口跳过额外递归编码；数值格式化器按精度复用。

## 本机接口测量

| 请求 | 响应大小 | 读完耗时 |
| --- | ---: | ---: |
| 批次目录 | 21,722 B | 28.05 ms |
| 本轮 4 场景摘要 | 5,273 B | 3.41 ms |
| 选中高写场景概览 | 262,367 B | 26.41 ms |
| 首屏合计 | 289,362 B | 57.87 ms |
| 按需完整高写配对 | 4,206,450 B | 128.70 ms |

这是本机一次顺序 HTTP 读取测量，耗时不包含前端资源加载与页面绘制。首屏数据量约从 35.5 MB 降为 0.29 MB，减少 99.2%。

## 验证

- 浏览器服务访问日志确认首次只请求目录、场景摘要及轻量概览，没有全批次或完整采样请求。首次打开线程后增加一次完整配对读取，切 CPU、时延 / 深度标签及返回已读场景复用采样。
- 正式 20 点可选，HTTP 完整记录仍包含预热及正式共 30 点；第 8 点 21–24 s 在标签间保持，按进程 / IO 流切换保留。CPU 页面全部主机显示 264 个逻辑 CPU；层指标仍明确待接入。
- 快速切换读场景后标题与指标一致；返回高写场景保留已选区间和 IO 展示方式。概览及案例入口正常加载，控制台没有错误。
- 新增加载测试 8 项、原版本诊断及时序测试 27 项、前端已有检查 29 项通过；最终 TypeScript 与 Vite 构建通过。
- 重启前后 11 个原始批次与 4 个案例的 ID 和 payload SHA256 完全一致。既有分析 / 评价兼容与旧库索引补齐在临时数据库测试中通过；真实页面验证未提交额外分析或评价。
