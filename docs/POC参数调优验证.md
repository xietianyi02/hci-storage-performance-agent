# POC 参数调优验证

验证日期：2026-09-29。入口：`http://127.0.0.1:8000/#poc`。

## 功能检查

- 参数注册支持类型、单位、范围、协议、设备及 fio 条件；场景保存参数定义快照。
- 场景内比较相同设备档案、版本、协议、完整已提供 fio 和来源，参数组合必须完整。重复次数不足、缺失受约束的 p99、任意样本超限时不进入候选。
- 分析通过实际 LangGraph 四个节点执行，原始实验、分析快照及专家评价追加保存。新增观测使当前分析失效，历史仍可查看。
- 独立临时数据库测试覆盖注册、条件匹配、输入类型、范围一致性、来源隔离、重复样本、逐次 p99 约束、候选排序、固定其他参数的观测关联及历史评价。
- 后端 42 项检查通过：37 项新增 POC 检查和 5 项既有 API、审批流程及版本配对回归检查。前端 29 项既有分窗、全 CPU 及双线程展示检查通过；TypeScript 与 Vite 构建通过。

## 页面检查

- 参数、实验对比、结论三个标签可切换；注册、新建场景和导入窗口均可打开及取消。
- 非法 JSON 显示格式错误；未填写观测值的导入模板被校验拒绝，没有写入实验。
- 示例场景包含 4 组完整配置、每组 3 次模拟观测。提高 bdev 深度的组显示更高 tierd 深度和磁盘时延、更低 IOPS，并因 p99 超限不参与候选。
- 结论展示四步执行记录、适用范围、候选参数和待验证状态；空评价理由时保存按钮禁用。
- 1440 × 960 和 390 × 844 视口检查通过，窄屏表格内部滚动，页面无横向溢出；浏览器没有控制台错误。验证后恢复默认视口，保留实验对比页面。
- 原有 11 个版本批次与 4 个案例的 ID 集合在重启前后相同。POC 示例保存在独立数据库，未修改原有记录。

## 当前接入范围

示例全部为模拟数据，两个参数没有真实环境绑定，验证时没有确认模拟建议为真实性能结论。真实参数名称、单位、范围以及读取、应用、回滚和分层采集接口待产品提供。当前支持注册、导入、分析与评价，尚未运行客户设备实验。
